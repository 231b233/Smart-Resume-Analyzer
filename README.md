# Smart Resume Analyzer 🚀

Smart Resume Analyzer is a Streamlit-based web application that analyzes resumes against job descriptions. It extracts candidate skills, experience, and compares them with job requirements to calculate compatibility scores, identify matching skills, and highlight missing skills.

## ✨ Features
- 📄 **Resume Parsing**: Extracts text and sections from PDF/DOCX resumes.
- 🎯 **Skill & Experience Extraction**: Automatically detects key technical and soft skills.
- 📊 **Job Compatibility Score**: Compares resume with job descriptions and gives match percentage.
- 💡 **Skill Gap Analysis**: Shows matching and missing keywords/skills for targeted resume improvement.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/231b233/Smart-Resume-Analyzer.git
   cd Smart-Resume-Analyzer
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application:**
   ```bash
   streamlit run app.py
   ```
